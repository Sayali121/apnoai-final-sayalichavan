# ApnoMart — Business Intelligence Dashboard

**Tool:** Python (Pandas + Matplotlib)  
**Data:** 1,200 order records, 01 May 2026–28 Oct 2026  
**Analyst:** Sayali Chavan

## Project files
- `dashboard.png` — executive dashboard screenshot
- `insights.pdf` — executive insights and strategic recommendation
- `apnomart-sales-data.csv` — source dataset (include only if permitted)

## KPI summary
- Total Sales: ₹16,261,998.30
- Total Profit: ₹4,419,736.17
- Total Orders: 1,200
- Weighted Profit Margin: 27.18%

## Key insights
1. Furniture is the largest revenue category (21.63% of sales).
2. Office Supplies has the strongest category margin (34.80%); Electronics has the weakest (18.88%).
3. Corporate is the largest segment by sales (26.51%), while Cash is the leading payment method (21.98%).

## Strategic recommendation
Pilot tighter Electronics discount controls and monitor contribution profit; protect Office Supplies availability due to its strong margin.

## Important data note
The supplied dataset spans May–October 2026. It does not contain a complete Q2-only period. The dashboard title therefore uses the actual available date range rather than mislabeling the analysis as Q2 2026.
